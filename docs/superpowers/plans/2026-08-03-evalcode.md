# evalcode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a private LLM benchmark — a skeleton Phoenix LiveView app, two coding tasks graded by held-out tests, and a bash script that produces a markdown results table.

**Architecture:** Human-driven. `bin/evalcode start` copies `skeleton/` into `runs/<run-id>/` and hands over `TASK.md`. The operator works the task in their own coding agent. `bin/evalcode grade` copies in tests the agent never saw, runs them, checks the compile, and appends a row to `RESULTS.md`. No model APIs are ever called.

**Tech Stack:** Elixir 1.20.2, Erlang/OTP 27, Phoenix 1.8 with LiveView 1.1, SQLite via `ecto_sqlite3`, bash, nix flake + direnv.

**Spec:** `docs/superpowers/specs/2026-08-03-evalcode-design.md`

## Global Constraints

- Elixir **1.20.2** and Erlang/**OTP 27**, pinned by `flake.nix`, enforced two ways. A `lib.assertMsg` on the resolved package versions fails `nix develop` at evaluation time, before any shell exists — this catches a wrong nixpkgs pin. The `shellHook`'s runtime check uses `exit 1`, not `return 1`, so a shadowed `elixir` earlier on `PATH` also fails. **`return 1` in a `shellHook` does not fail anything**: under `nix develop --command` bash reports `return: can only 'return' from a function or sourced script`, execution continues, and the exit code is 0. Any change here must be verified by forcing a version mismatch and confirming a non-zero exit.
- nixpkgs pinned to `github:NixOS/nixpkgs/7a1a64774a5fd0b0cd39ac95d0e170ace8b266a0` — this revision is known to provide `elixir-1.20.2`.
- Phoenix **1.8**, LiveView **1.1**. Database is **SQLite** via `ecto_sqlite3`.
- The skeleton app is named `Warung`, OTP app `:warung`.
- Tests that drive a LiveView use **`Phoenix.LiveViewTest`** — never `phoenix_test` or another wrapper. The benchmark must not measure whether a model knows a third-party test library. Tests of plain modules use plain `ExUnit.Case`; this constraint is about which LiveView testing library is allowed, not a requirement that every test drive a LiveView.
- Elixir 1.20 has **no user-facing type annotation syntax**. Never write `@spec`-style set-theoretic annotations; they do not exist in this version.
- The harness is **bash**. No escript, no `verify` command, no `results.jsonl`, no `--docs` flag. These were deliberately excluded by the spec.
- Any test whose assertions depend on data being visible to a *separate* process (every LiveView test) must be `async: false` and use a shared Ecto sandbox owner.
- `runs/` is gitignored. The agent under test only ever opens `runs/<run-id>/`.

```nix
{
  description = "Pinned development shell for evalcode";

  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/7a1a64774a5fd0b0cd39ac95d0e170ace8b266a0";
  };

  outputs =
    { nixpkgs, ... }:
    let
      systems = [
        "aarch64-darwin"
        "x86_64-darwin"
        "aarch64-linux"
        "x86_64-linux"
      ];

      forAllSystems =
        function:
        nixpkgs.lib.genAttrs systems (
          system:
          function (import nixpkgs {
            inherit system;
            config.allowUnfree = false;
          })
        );
    in
    {
      devShells = forAllSystems (
        pkgs:
        let
          inherit (pkgs) lib;
          beam = pkgs.beam.packages.erlang_27;
          elixir = beam.elixir_1_20;

          # Evaluated before any shell exists, so a wrong nixpkgs pin fails
          # `nix develop` itself rather than printing a warning nobody reads.
          pinnedVersionsOk =
            lib.assertMsg
              (lib.versionAtLeast elixir.version "1.20" && lib.versionOlder elixir.version "1.21")
              "evalcode: pinned nixpkgs must provide Elixir 1.20.x, got ${elixir.version}"
            && lib.assertMsg
              (lib.versionAtLeast beam.erlang.version "27" && lib.versionOlder beam.erlang.version "28")
              "evalcode: pinned nixpkgs must provide Erlang/OTP 27, got ${beam.erlang.version}";

          commonPackages = with pkgs; [
            beam.erlang
            beam.rebar3
            elixir
            cacert
            curl
            git
            gnumake
            nodejs_22
            openssl
            pkg-config
            rsync
            sqlite
            stdenv.cc
            zlib
          ];

          linuxPackages = with pkgs; [ inotify-tools ];
          darwinPackages = with pkgs; [ libiconv ];
        in
        assert pinnedVersionsOk;
        {
          default = pkgs.mkShell {
            packages =
              commonPackages
              ++ pkgs.lib.optionals pkgs.stdenv.isLinux linuxPackages
              ++ pkgs.lib.optionals pkgs.stdenv.isDarwin darwinPackages;

            shellHook = ''
              export MIX_HOME="$PWD/.nix-mix"
              export HEX_HOME="$PWD/.nix-hex"
              export MIX_XDG=1
              export ERL_AFLAGS="-kernel shell_history enabled"
              export LANG="en_US.UTF-8"
              export PATH="$MIX_HOME/bin:$HEX_HOME/bin:$PATH"

              mkdir -p "$MIX_HOME" "$HEX_HOME"

              elixir_version="$(elixir --version | tr '\n' ' ' | sed 's/[[:space:]]*$//')"
              otp_release="$(erl -noshell -eval 'io:format("~s", [erlang:system_info(otp_release)]), halt().' 2>/dev/null)"

              case "$elixir_version" in
                *"Elixir 1.20."*) ;;
                *)
                  echo "Expected Elixir 1.20.x from the pinned flake, got: $elixir_version" >&2
                  exit 1
                  ;;
              esac

              if [ "$otp_release" != "27" ]; then
                echo "Expected Erlang/OTP 27 from the pinned flake, got: $otp_release" >&2
                exit 1
              fi

              echo "evalcode shell: $elixir_version"
            '';
          };
        }
      );

      formatter = forAllSystems (pkgs: pkgs.nixfmt-rfc-style);
    };
}
```

```elixir
defmodule Warung.Catalog.Product do
  use Ecto.Schema
  import Ecto.Changeset

  schema "products" do
    field :sku, :string
    field :name, :string
    field :price, :decimal
    field :stock, :integer, default: 0

    timestamps(type: :utc_datetime)
  end

  def changeset(product, attrs) do
    product
    |> cast(attrs, [:sku, :name, :price, :stock])
    |> validate_required([:sku, :name, :price])
    |> validate_number(:stock, greater_than_or_equal_to: 0)
    |> unique_constraint(:sku)
  end
end
```

**Interfaces:**
- Consumes: `Warung.Catalog.Product`, `Warung.Repo`, `Warung.Catalog.create_product/1`
- Produces:
  - `Warung.Orders.Order` — `customer_email :string`, `total :decimal`, `has_many :items`
  - `Warung.Orders.OrderItem` — `quantity :integer`, `unit_price :decimal`, `belongs_to :order`, `belongs_to :product`
  - `Warung.Orders.create_order/1` — takes `%{customer_email: String.t(), items: [%{product_id: integer(), quantity: integer()}]}`, returns `{:ok, %Order{}}` with `items` preloaded, or `{:error, atom() | %Ecto.Changeset{}}`. The atom errors are `:no_items`, `:product_not_found`, and `:invalid_quantity`. **`price_items/1` validates every item before anything is inserted**, so a caller can never drive an `OrderItem` changeset to fail — which matters because `repo.insert!` inside `Ecto.Multi.run` reraises rather than producing `{:error, ...}`, and an escaping `Ecto.InvalidChangesetError` would break the documented contract.
  - `Warung.Orders.list_orders/0` → `[%Order{}]` newest first, `items` preloaded

**Ordering matters:** `list_orders/0` returns newest first. Task 8's held-out tests depend on this.

```elixir
  def change do
    create table(:orders) do
      add :customer_email, :string, null: false
      add :total, :decimal, null: false

    end

    create table(:order_items) do
      add :quantity, :integer, null: false
      add :unit_price, :decimal, null: false
```

```elixir
defmodule Warung.Orders do
  @moduledoc """
  Placing and listing customer orders.
  """

  import Ecto.Query, warn: false

  alias Ecto.Multi
  alias Warung.Catalog.Product
  alias Warung.Orders.Order
  alias Warung.Orders.OrderItem
  alias Warung.Repo

  def list_orders do
    Repo.all(from o in Order, order_by: [desc: o.inserted_at, desc: o.id], preload: [:items])
  end

  def create_order(attrs) do
    items = Map.get(attrs, :items, [])

    with {:ok, priced} <- price_items(items) do
      total = Enum.reduce(priced, Decimal.new(0), &Decimal.add(line_total(&1), &2))

      Multi.new()
      |> Multi.insert(:order, Order.changeset(%Order{}, %{
        customer_email: Map.get(attrs, :customer_email),
        total: total
      }))
      |> Multi.run(:items, fn repo, %{order: order} ->
        inserted =
          Enum.map(priced, fn item ->
            repo.insert!(OrderItem.changeset(%OrderItem{}, Map.put(item, :order_id, order.id)))
          end)

        {:ok, inserted}
      end)
      |> Repo.transaction()
      |> case do
        {:ok, %{order: order, items: items}} -> {:ok, %{order | items: items}}
        {:error, _step, changeset, _changes} -> {:error, changeset}
      end
    end
  end

  defp price_items([]), do: {:error, :no_items}

  defp price_items(items) do
    Enum.reduce_while(items, {:ok, []}, fn item, {:ok, acc} ->
      with {:ok, quantity} <- validate_quantity(Map.get(item, :quantity, 1)),
           %Product{} = product <- Repo.get(Product, Map.get(item, :product_id)) do
        priced = %{product_id: product.id, quantity: quantity, unit_price: product.price}
        {:cont, {:ok, acc ++ [priced]}}
      else
        nil -> {:halt, {:error, :product_not_found}}
        {:error, reason} -> {:halt, {:error, reason}}
      end
    end)
  end

  defp validate_quantity(quantity) when is_integer(quantity) and quantity > 0, do: {:ok, quantity}
  defp validate_quantity(_quantity), do: {:error, :invalid_quantity}

  defp line_total(%{unit_price: price, quantity: quantity}) do
    Decimal.mult(price, Decimal.new(quantity))
  end
end
```

```elixir
  use WarungWeb, :live_view

  alias Warung.Catalog
  alias Warung.Orders

  @impl true
  def mount(_params, _session, socket) do
    {:ok,
     socket
     |> assign(:page_title, "Orders")
     |> assign(:products, Catalog.list_products())
     |> assign(:error, nil)
     |> stream(:orders, Orders.list_orders())}
  end

  @impl true
  def handle_event("place", params, socket) do
    with {:ok, attrs} <- build_attrs(params),
         {:ok, order} <- Orders.create_order(attrs) do
      {:noreply,
       socket
       |> assign(:error, nil)
       |> stream_insert(:orders, order, at: 0)}
    else
      _ -> {:noreply, assign(socket, :error, "That order could not be placed.")}
    end
  end

  # `min="1"` on the input is client-side only. Neither parsing nor anything
  # downstream of it may raise, so magnitude is bounded here: Elixir integers
  # are arbitrary precision, but SQLite's are 64-bit, and handing it a bignum
  # raises Exqlite.Error from inside the driver where `with` cannot catch it.
  @max_sqlite_int 9_223_372_036_854_775_807

  defp build_attrs(params) do
    with {product_id, ""} <- Integer.parse(params["product_id"] || ""),
         {quantity, ""} <- Integer.parse(params["quantity"] || ""),
         true <- in_range?(product_id) and in_range?(quantity) do
      {:ok,
       %{
         customer_email: params["customer_email"],
         items: [%{product_id: product_id, quantity: quantity}]
       }}
    else
      _ -> :error
    end
  end

  defp in_range?(n), do: n > 0 and n <= @max_sqlite_int

  @impl true
  def render(assigns) do
    ~H"""
    <div class="mx-auto max-w-3xl p-6">

        <input type="number" name="quantity" value="1" min="1" class="input input-bordered w-24" />
```

Create `bin/evalcode`:

```bash
#!/usr/bin/env bash

# `source` runs in the caller's shell, so an unconditional `set -e` here would
# turn on errexit in whatever sourced us and stay on after we return. Task 7
# sources this file for its pure helpers and then runs `mix test`, whose
# non-zero exit is a meaningful result rather than an error — a leaked errexit
# would abort grading on the first failing test suite.
[ "${EVALCODE_LIB_ONLY:-0}" = "1" ] || set -euo pipefail

ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"

# Paths excluded from the base-vs-run diff. Build artefacts and the database
# change on every run and would drown the suppression scan in noise.
DIFF_EXCLUDES=(-x deps -x _build -x '.elixir_ls' -x '*.db' -x '*.db-shm' -x '*.db-wal' -x node_modules)

# --- pure helpers, unit-tested by test/evalcode_test.sh ----------------------

# run_id_for <date> <model> <task-id>  ->  2026-08-03-opus5-01
run_id_for() {
  local date="$1" model="$2" task="$3"
  printf '%s-%s-%s\n' "$date" "$model" "${task%%-*}"
}

# evalcode_status <task-id> <pass|fail> <compile-result> <yes|no suppressions>
evalcode_status() {
  local task="$1" tests="$2" compile="$3" suppressions="$4"

  [ "$tests" = pass ] || { echo no; return; }
  [ "$suppressions" = no ] || { echo no; return; }

  if [ "$task" = "02-type-clean" ] && [ "$compile" != clean ]; then
    echo no
    return
  fi

  echo yes
}

# format_row <task> <model> <harness> <completed> <duration> <cost> <compile>
format_row() {
  local cost="$6"
  if [ -n "$cost" ]; then cost="\$$cost"; else cost="—"; fi
  printf '| %s | %s | %s | %s | %s | %s | %s |\n' "$1" "$2" "$3" "$4" "$5" "$cost" "$7"
}

# --- subcommands ------------------------------------------------------------

cmd_start() {
  local task="${1:?usage: evalcode start <task-id> <model> <harness>}"
  local model="${2:?usage: evalcode start <task-id> <model> <harness>}"
  local harness="${3:?usage: evalcode start <task-id> <model> <harness>}"

  [ -d "$ROOT/tasks/$task" ] || { echo "no such task: $task" >&2; exit 1; }

  local run_id run base meta
  run_id="$(run_id_for "$(date +%Y-%m-%d)" "$model" "$task")"
  run="$ROOT/runs/$run_id"
  base="$ROOT/runs/$run_id.base"
  meta="$ROOT/runs/$run_id.meta"

  [ -e "$run" ] && { echo "run already exists: $run" >&2; exit 1; }

  mkdir -p "$run"
  cp -R "$ROOT/skeleton/." "$run/"

  # `skeleton/` accumulates a dev and test database from being worked in
  # directly. `mix ecto.create` will not overwrite an existing file, so
  # without this every run would start with whatever rows happened to be
  # sitting in the author's local database — and two runs a week apart
  # would not start from the same state.
  rm -f "$run"/*.db "$run"/*.db-shm "$run"/*.db-wal

  if [ -d "$ROOT/tasks/$task/overlay" ]; then
    cp -R "$ROOT/tasks/$task/overlay/." "$run/"
  fi

  cp "$ROOT/tasks/$task/task.md" "$run/TASK.md"

  # Snapshot source only. `skeleton/deps` and `skeleton/_build` are ~144MB
  # together; copying them here would double every run's cost to produce a
  # snapshot whose entire purpose is a diff that excludes those paths anyway.
  rsync -a --exclude deps --exclude _build --exclude '.elixir_ls' "$run/" "$base/"

  printf 'task=%s\nmodel=%s\nharness=%s\nstarted=%s\n' \
    "$task" "$model" "$harness" "$(date -u +%Y-%m-%dT%H:%M:%SZ)" > "$meta"

  (cd "$run" && mix deps.get && mix ecto.setup) >/dev/null

  echo "$run"
}

# --- dispatch ---------------------------------------------------------------

if [ "${EVALCODE_LIB_ONLY:-0}" = "1" ]; then
  return 0 2>/dev/null || exit 0
fi

case "${1:-}" in
  start) shift; cmd_start "$@" ;;
  *)
    echo "usage: evalcode start <task-id> <model> <harness>" >&2
    exit 1
    ;;
esac
```

Insert `elapsed_minutes` directly after `format_row`:

```bash
# elapsed_minutes <iso8601-start> <iso8601-end>  ->  14m
#
# Returns non-zero on anything it cannot parse. This matters more than it
# looks: bash does not inherit errexit into command substitutions unless
# `shopt -s inherit_errexit` is set, and that option does not exist in bash
# 3.2, which is what macOS ships. So a `date` failure inside this function
# cannot abort the caller on its own — an empty `start_s` would be coerced to
# 0 by arithmetic and yield minutes-since-the-epoch. Observed: a malformed
# `started` produced `29762072m` and exited 0. Every caller must check the
# return status explicitly.
elapsed_minutes() {
  local start_s end_s

  if [ -z "${1:-}" ] || [ -z "${2:-}" ]; then
    echo "elapsed_minutes: missing timestamp (start='${1:-}' end='${2:-}')" >&2
    return 1
  fi

  if date -u -d "1970-01-01" +%s >/dev/null 2>&1; then
    start_s="$(date -u -d "$1" +%s 2>/dev/null)" || start_s=""   # GNU date
    end_s="$(date -u -d "$2" +%s 2>/dev/null)" || end_s=""
  else
    start_s="$(date -u -j -f "%Y-%m-%dT%H:%M:%SZ" "$1" +%s 2>/dev/null)" || start_s=""   # BSD
    end_s="$(date -u -j -f "%Y-%m-%dT%H:%M:%SZ" "$2" +%s 2>/dev/null)" || end_s=""
  fi

  if [ -z "$start_s" ] || [ -z "$end_s" ]; then
    echo "elapsed_minutes: unparseable timestamp (start='$1' end='$2')" >&2
    return 1
  fi

  printf '%dm\n' "$(( (end_s - start_s) / 60 ))"
}
```

```bash
cmd_grade() {
  local run_id="${1:?usage: evalcode grade <run-id> [--cost N] [--duration Nm]}"
  shift

  local cost="" duration=""
  while [ $# -gt 0 ]; do
    case "$1" in
      --cost) cost="${2:?--cost needs a value}"; shift 2 ;;
      --duration) duration="${2:?--duration needs a value}"; shift 2 ;;
      *) echo "unknown option: $1" >&2; exit 1 ;;
    esac
  done

  local run="$ROOT/runs/$run_id" base="$ROOT/runs/$run_id.base" meta="$ROOT/runs/$run_id.meta"
  [ -d "$run" ] || { echo "no such run: $run" >&2; exit 1; }
  [ -f "$meta" ] || { echo "missing meta: $meta" >&2; exit 1; }
  # Without this, `diff -rN` against a missing directory silently treats it as
  # empty, so every line in the run reads as freshly added and any pre-existing
  # suppression attribute is misattributed to the model.
  [ -d "$base" ] || { echo "missing base snapshot: $base" >&2; exit 1; }

  # shellcheck disable=SC1090
  source "$meta"   # provides: task, model, harness, started

  # Scan for suppression attributes BEFORE the held-out tests are copied in,
  # so the diff contains only what the model actually wrote.
  #
  # Written to a file rather than piped into grep. `diff` exits 1 whenever it
  # finds differences — the normal case — and under `set -o pipefail` that 1
  # wins over grep's 0, so a piped form reports "no suppressions" for every
  # input, forever. An anti-cheat that cannot fire is worse than none, because
  # it implies a protection that is not there.
  #
  # -N diffs a file present only in the run against /dev/null, so a suppression
  # added in a brand-new file is scanned too.
  local suppressions
  diff -rN "${DIFF_EXCLUDES[@]}" "$base" "$run" > "$run.diff.log" 2>/dev/null || true

  if grep -qE '^> *@(compile|dialyzer)' "$run.diff.log"; then
    suppressions=yes
  else
    suppressions=no
  fi

  cp -R "$ROOT/tasks/$task/holdout/." "$run/test/"

  # The generated `mix test` alias creates and migrates but never drops, so
  # rows a model wrote outside a sandboxed test — an iex session, a `mix run`
  # — survive into grading and fail tests that have nothing to do with the
  # task. That scores a model as failing for work it did correctly, which is
  # worse than a false pass because it looks like a real result.
  (cd "$run" && MIX_ENV=test mix ecto.drop --quiet) >/dev/null 2>&1 || true

  local tests compile completed
  if (cd "$run" && mix test) > "$run.test.log" 2>&1; then tests=pass; else tests=fail; fi

  # Three states, not two. A hard CompileError — the `~p` route failure Task 2
  # documented, for one — contains no `warning:` lines at all, so counting them
  # would label a build that never compiled as "0 warnings", which reads as
  # almost-clean. The route flag exists because that is the one confounder
  # known to fail this gate for reasons unrelated to type inference, and the
  # exit code cannot distinguish it.
  local warn_count
  if (cd "$run" && mix compile --force --warnings-as-errors) > "$run.compile.log" 2>&1; then
    compile=clean
  else
    warn_count="$(grep -c 'warning:' "$run.compile.log" || true)"
    if [ "$warn_count" -eq 0 ]; then
      compile="error"
    elif grep -qE 'no route path for [A-Za-z0-9_.]*Router matches' "$run.compile.log"; then
      compile="$warn_count warnings (routes)"
    else
      compile="$warn_count warnings"
    fi
  fi

  if [ -z "$duration" ]; then
    duration="$(elapsed_minutes "$started" "$(date -u +%Y-%m-%dT%H:%M:%SZ)")" || {
      echo "grade: cannot compute duration from meta (started='$started')" >&2
      echo "grade: pass --duration explicitly, or repair $meta" >&2
      exit 1
    }
  fi
  completed="$(evalcode_status "$task" "$tests" "$compile" "$suppressions")"

  local row
  row="$(format_row "$task" "$model" "$harness" "$completed" "$duration" "$cost" "$compile")"
  echo "$row" >> "$ROOT/RESULTS.md"
  echo "$row"

  if [ "$suppressions" = yes ]; then
    echo "note: compiler suppression attributes were added — recorded as not completed" >&2
  fi
  echo "logs: $run.test.log  $run.compile.log  $run.diff.log" >&2
}
```

```elixir
    name =
      case customer do
        %{name: n} when is_binary(n) -> n
        _ -> nil
      end

    String.upcase(name)
  end

  # 3. is_map_key / not_set(): inside this branch `:timeout` is known absent.
  def timeout_for(opts) when is_map(opts) do
    if not is_map_key(opts, :timeout) do
      opts.timeout
    else
      opts.timeout
    end
  end

  # 4. tuple size bounds: the guard proves the tuple has fewer than 3 elements.
  def third_field(row) when tuple_size(row) < 3 do
    elem(row, 2)
  end

  # 5. dynamic() compatibility: `decoded` is `list() or map()`, and list() is
  #    disjoint from what Map.fetch!/2 accepts.
  def currency_from(payload) when is_binary(payload) do
    decoded = JSON.decode!(payload)

    decoded =
      case decoded do
        list when is_list(list) -> list
        map when is_map(map) -> map
      end

    Map.fetch!(decoded, "currency")
  end
end
```

```elixir
defmodule WarungWeb.OrderParams do
  @moduledoc """
  Normalisation helpers for order form parameters and imported payloads.
  """

  @default_timeout 5_000

  def status_label(nil), do: "unknown"
  def status_label(status), do: to_string(status)

  def display_name(customer) do
    case customer do
      %{name: n} when is_binary(n) -> String.upcase(n)
      _ -> "ANONYMOUS"
    end
  end

  def timeout_for(opts) when is_map(opts) do
    Map.get(opts, :timeout, @default_timeout)
  end

  def third_field(row) when is_tuple(row) and tuple_size(row) >= 3, do: elem(row, 2)
  def third_field(row) when is_tuple(row), do: nil

  def currency_from(payload) when is_binary(payload) do
    case JSON.decode!(payload) do
      %{"currency" => currency} -> currency
      map when is_map(map) -> {:error, :missing_currency}
      _ -> {:error, :not_an_object}
    end
  end
end
```
